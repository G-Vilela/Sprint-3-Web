# Projeto React FIAP

Projeto migrado de HTML, CSS e JavaScript puro para React, utilizando componentes funcionais, propriedades entre componente pai e filho, localStorage e operações com Math.

## Onde a IA foi usada e como
A Inteligência Artificial foi utilizada como ferramenta de apoio durante o desenvolvimento do projeto, principalmente na migração da estrutura de HTML, CSS e JavaScript para React e na implementação das funcionalidades relacionadas ao objeto Math. A IA auxiliou na organização do código em componentes funcionais, na comunicação entre componentes pai e filho e na adaptação das funcionalidades existentes para React. Também teve maior participação na implementação e compreensão de métodos como Math.random(), Math.floor(), Math.round() e Math.sqrt(), utilizados para realizar randomizações, arredondamentos e outras operações matemáticas dentro da aplicação.

## Tecnologias utilizadas
- React
- JavaScript
- HTML5
- CSS3
- Vite
- localStorage

## Como instalar as dependências
Abra o terminal na pasta do projeto e execute:

```bash
npm install
```

## Como executar o projeto
Depois da instalação, execute:

```bash
npm run dev
```

Abra no navegador o endereço informado pelo Vite.

## Gerar versão de produção
```bash
npm run build
```
